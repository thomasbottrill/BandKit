# Bandkit live capture test

These are short, approximately 10-second source captures from the live Bandkit extension running on a Bandcamp album page in the Lantana Chrome profile.

## Clips

- `raw/01-player-live.mov` — continuous player, waveform, artwork, playback analysis
- `raw/02-queue-playlists-live.mov` — populated Now Playing queue with four tracks
- `raw/03-dj-tools-live.mov` — page-level DJ tools, BPM, tempo, waveform and track analysis
- `raw/04-cart-recovery-live-2.mov` — populated cart recovery view with nine cart items
- `raw/05-themes-settings-live.mov` — theme/settings panel with live themed Bandcamp UI

The captures are intentionally raw source footage. The next pass can crop the Chrome window, add Figma branding, and create editable zooms/callouts in DaVinci Resolve.
